# Materiały źródłowe do dossier

Tutaj wrzucaj surowe materiały — zrzuty ekranu, eksporty, PDF-y — z których buduję
zakładki dossier. Wszystko, co tu trafi, jest w repozytorium, więc mam do tego
dostęp w każdej sesji bez przesyłania plików w czacie.

## Gdzie co wrzucać

| Katalog | Co tam trafia |
|---|---|
| `research/screenshots/` | zrzuty ekranu (PNG, JPG) |
| `research/exports/` | eksporty z narzędzi (CSV, XLSX, PDF, JSON) |
| `research/notes/` | odczyty i ustalenia, które już przetworzyłem |

## Jak nazywać pliki

```
RRRR-MM-DD_narzedzie_domena_sekcja.png
```

Przykłady:

```
2026-09-16_semrush_aichamber_przeglad-domeny.png
2026-09-16_semrush_aichamber_linki-zwrotne.png
2026-09-16_semrush_ceeaisummit_slowa-kluczowe.png
2026-09-16_similarweb_aichamber_kanaly.pdf
```

Jeśli nazwa wyjdzie inna — nic się nie stanie, rozpoznam zawartość. Nazewnictwo
jest po to, żeby po kilkudziesięciu plikach dało się je przeglądać.

## Co mi pomaga, a co przeszkadza

**Pomaga:**

- **Eksport zamiast zrzutu, jeśli narzędzie go oferuje.** Semrush i SimilarWeb mają
  przycisk „Eksportuj" przy większości tabel. CSV jest dokładny, zrzut trzeba
  odczytywać z obrazu i przy małych czcionkach bywa niejednoznaczny.
- **Widoczny kontekst filtrów.** Kraj, zakres dat, urządzenie, tryb (domena główna
  vs subdomeny). Bez tego nie wiem, czy liczba dotyczy Polski czy świata.
- **Pełne tabele.** Jeśli lista ma „Zobacz szczegóły", wartościowy jest widok po
  rozwinięciu, nie pięć pierwszych wierszy.
- **Zrzut całej strony** zamiast fragmentu — kontekst wokół liczby często decyduje
  o jej interpretacji.

**Przeszkadza:**

- Zdjęcie ekranu telefonem zamiast zrzutu.
- Kadr bez nagłówka sekcji — nie wiem, czego dotyczy tabela.
- Zrzut z rozmytym tekstem po kompresji.

## Po wrzuceniu

Napisz w czacie, że pliki są w repo. Zaciągnę je, odczytam i wdrożę do odpowiednich
zakładek — z przypisami i stopniem wiarygodności, tak jak pozostałe źródła.
